DAY 11 - Project brief + actual project prompt (build expense-pro)   
Time plan: 6 brief | 6 plan | 12 build | 6 run and test (Option B and comparison = extra)
------------------------------------------------------------------------------------------
Project start order:  1 instructions (Day 9-10)  >  2 PROJECT BRIEF (today)  >  3 PLAN  >  4 BUILD
TRAINER TIP: run this day once before class. If the build is slow in class, use your pre-built copy
for the last 6 minutes and still show the prompts.
 
PART A - project brief file (6 min)   step 2 of project start
1. in expense-pro create folder docs and file docs/PROJECT_BRIEF.md
2. paste and save:
 
# Smart Expense Tracker
Purpose: help a person record daily expenses and see monthly totals.
Users: individuals, desktop first, also mobile.
Categories: Food, Travel, Bills, Shopping, Other.
Features: add expense (amount, category, date, note), list with delete, month filter,
total and per-category summary.
Out of scope: login, database, charts (added in later days).
 
3.for explanation :
   instruction file = RULES, always on       (how to write code)
   project brief    = FACTS about this app   (what to build) - you attach it when needed
 
PART B - plan, then build 
 
STEP 1 - plan with Plan mode 
1. new chat (+), choose ASK mode
2. drag docs/PROJECT_BRIEF.md from Explorer into the chat box (check the file chip)
3. paste this prompt:
 
--- PROMPT START ---
Using this project brief, plan the project: folder and file structure, the expense data model,
the functions in each file, a test plan, and numbered build steps.
Ask me questions if anything is unclear. Do not write code yet.
--- PROMPT END ---
 
4. answer any questions it asks (short answers)
5. review the plan - tick all four:
   [ ] has index.html, css/styles.css, js/app.js, js/storage.js, js/utils.js, tests/
   [ ] utils.js has calculateTotal, groupByCategory, filterByMonth
   [ ] nothing from "out of scope" (no login, no database, no charts)
   [ ] has a test plan
   if not: reply "Remove X" or "Add Y" and let it update the plan
6. SAVE the plan: select the whole plan text > copy > create docs/BUILD_PLAN.md > paste > save
   (a NEW chat does not remember this chat, so the plan must be a file)
 
STEP 2 - build with Agent mode (12 min)
1. new chat (+), choose AGENT mode
2. drag docs/PROJECT_BRIEF.md and docs/BUILD_PLAN.md into the chat box
3. paste this prompt:
 
--- PROMPT START ---
Build the project from the attached brief and plan.
Create or update: index.html, css/styles.css, js/app.js (UI), js/storage.js (localStorage only),
js/utils.js (calculateTotal, groupByCategory, filterByMonth), package.json with Vitest and a
test script, tests/utils.test.js.
Keep the existing formatMoney in js/utils.js and the .expense-card style in css/styles.css.
Follow the project instructions. Work step by step.
At the end tell me the exact commands to install, test and run.
--- PROMPT END ---
 
4. while it works, teach (same as Day 4):
   - read every approval popup before clicking Allow
   - click each changed file to see the diff
   - Keep = accept, Undo = reject
5. when done, click Keep for all files
 
PART C - run, test and verify 
BEFORE CLASS: Node.js LTS must be installed on every machine. In the terminal run  node -v  and  npm -v
              both must print a version. If not: install Node.js LTS from nodejs.org, restart VS Code.
 
STEP 1 - open the terminal in the project folder 
1. press ctrl+`  (backtick) to open the terminal
2. type  ls  (or  dir  in Command Prompt) and press Enter
3. you must see package.json in the list
   if not: File > Open Folder > select expense-pro, then open the terminal again
 
STEP 2 - install and run the tests    needs internet
1. type:  npm install        wait until it finishes (node_modules folder appears) - runs only once
2. type:  npm test           expected: all tests passed (green)
3. if the test command keeps waiting for changes, press q, then in package.json change the
   test script to  "test": "vitest run"  and run  npm test  again
 
STEP 3 - start the app 
1. type:  npx serve
2. first time it asks "Ok to proceed?"  > type y and press Enter
3. copy the link shown (example http://localhost:3000)
4. ctrl+shift+P > Browser: Open Integrated Browser > paste the link
   (do not double-click index.html: ES modules need a server)
5. leave this terminal running; to stop the server press ctrl+C; use the + icon for a second terminal
 
STEP 4 - test in the browser 
   [ ] add 3 expenses
   [ ] refresh page - data still there
   [ ] filter by month - list and totals change
   [ ] delete one expense
   [ ] empty list shows a message
